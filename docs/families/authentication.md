            # Authentication

            Validates identity entry points, recovery flows, and authentication state transitions.

            ## Reviewed subjects

            - password login
- single sign-on callback
- multi-factor challenge
- password reset
- account recovery
- device enrollment
- service credential flow
- session reauthentication
- invitation acceptance

            ## Control themes

            - uses consistent failure responses
- bounds repeated attempts
- invalidates superseded credentials

            Each rule requires explicit offline evidence. A rule definition adds report context and does not initiate a scan or execute supplied reproduction text.
