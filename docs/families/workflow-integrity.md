            # Workflow integrity

            Preserves required approvals, ordering, uniqueness, and state transitions in business workflows.

            ## Reviewed subjects

            - approval workflow
- password recovery
- account invitation
- payment release
- report publication
- backup restore
- role assignment
- data deletion
- integration onboarding

            ## Control themes

            - enforces required step order
- prevents duplicate completion
- records the approving identity

            Each rule requires explicit offline evidence. A rule definition adds report context and does not initiate a scan or execute supplied reproduction text.
