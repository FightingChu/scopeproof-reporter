            # Output encoding

            Ensures untrusted values remain data in each rendered or serialized output context.

            ## Reviewed subjects

            - HTML text
- HTML attribute
- URL parameter
- JavaScript data
- CSS value
- CSV cell
- JSON response
- log record
- email body

            ## Control themes

            - uses context-specific encoding
- preserves structural boundaries
- declares the intended media type

            Each rule requires explicit offline evidence. A rule definition adds report context and does not initiate a scan or execute supplied reproduction text.
