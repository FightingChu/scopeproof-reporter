            # Transport security

            Protects service traffic and endpoint identity across approved communication paths.

            ## Reviewed subjects

            - public web endpoint
- administration endpoint
- JSON API
- webhook receiver
- download service
- upload service
- health endpoint
- metrics endpoint
- callback endpoint

            ## Control themes

            - requires encrypted transport
- uses an approved protocol policy
- presents the expected endpoint identity

            Each rule requires explicit offline evidence. A rule definition adds report context and does not initiate a scan or execute supplied reproduction text.
