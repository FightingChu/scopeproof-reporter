            # Privacy controls

            Aligns personal-data use, disclosure, correction, export, and deletion with documented purpose.

            ## Reviewed subjects

            - profile field
- contact preference
- location record
- usage event
- support record
- account export
- deletion request
- consent record
- shared report

            ## Control themes

            - states and enforces its purpose
- supports the required subject action
- limits disclosure in reports

            Each rule requires explicit offline evidence. A rule definition adds report context and does not initiate a scan or execute supplied reproduction text.
