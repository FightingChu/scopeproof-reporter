            # Input validation

            Defines accepted structure, size, type, and interpretation for external input fields.

            ## Reviewed subjects

            - query parameter
- JSON field
- form field
- path segment
- header value
- filter expression
- sort key
- identifier
- bulk import field

            ## Control themes

            - uses a positive syntax contract
- applies a bounded size
- keeps data separate from interpreters

            Each rule requires explicit offline evidence. A rule definition adds report context and does not initiate a scan or execute supplied reproduction text.
