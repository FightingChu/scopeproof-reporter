            # API contracts

            Reviews method, schema, pagination, idempotency, and error behavior for service interfaces.

            ## Reviewed subjects

            - create operation
- read operation
- update operation
- delete operation
- bulk operation
- search operation
- webhook operation
- export operation
- status operation

            ## Control themes

            - accepts only documented methods and media types
- uses bounded pagination or batch size
- handles retries without duplicate effects

            Each rule requires explicit offline evidence. A rule definition adds report context and does not initiate a scan or execute supplied reproduction text.
