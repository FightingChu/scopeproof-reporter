            # Data protection

            Controls sensitive data collection, storage, exposure, export, and retention.

            ## Reviewed subjects

            - account identifier
- contact detail
- payment metadata
- authentication secret
- support transcript
- audit record
- analytics event
- exported record
- backup record

            ## Control themes

            - collects only required values
- protects stored values
- enforces retention and deletion

            Each rule requires explicit offline evidence. A rule definition adds report context and does not initiate a scan or execute supplied reproduction text.
