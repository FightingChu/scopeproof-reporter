            # Dependency hygiene

            Tracks dependency provenance, version intent, build integrity, and update ownership.

            ## Reviewed subjects

            - runtime library
- build tool
- container base
- browser package
- CLI package
- test utility
- code generator
- binary helper
- deployment action

            ## Control themes

            - has a reviewable version constraint
- comes from an approved source
- has an update and removal owner

            Each rule requires explicit offline evidence. A rule definition adds report context and does not initiate a scan or execute supplied reproduction text.
