            # Session management

            Reviews the creation, binding, rotation, expiration, and revocation of session state.

            ## Reviewed subjects

            - browser session
- mobile session
- administrator session
- remember-me token
- API refresh token
- password-reset session
- step-up session
- impersonation session
- support session

            ## Control themes

            - uses protected token storage
- rotates after privilege change
- expires and revokes predictably

            Each rule requires explicit offline evidence. A rule definition adds report context and does not initiate a scan or execute supplied reproduction text.
