            # File handling

            Constrains file names, content, storage, retrieval, and lifecycle operations.

            ## Reviewed subjects

            - document upload
- image upload
- archive import
- report export
- attachment download
- temporary file
- backup package
- avatar upload
- configuration import

            ## Control themes

            - validates content independently of the name
- uses a bounded storage path
- applies size and lifecycle limits

            Each rule requires explicit offline evidence. A rule definition adds report context and does not initiate a scan or execute supplied reproduction text.
