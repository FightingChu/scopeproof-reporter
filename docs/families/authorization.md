            # Authorization

            Checks object, function, and tenant boundaries after identity has been established.

            ## Reviewed subjects

            - user profile
- billing record
- project resource
- administration action
- export job
- support case
- tenant setting
- API object
- background task

            ## Control themes

            - enforces object ownership
- enforces role boundaries
- isolates tenant context

            Each rule requires explicit offline evidence. A rule definition adds report context and does not initiate a scan or execute supplied reproduction text.
