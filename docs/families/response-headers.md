            # Response headers

            Applies browser and intermediary response controls to each relevant content surface.

            ## Reviewed subjects

            - HTML document
- authentication response
- account page
- administration page
- file download
- error page
- embedded content
- static asset
- redirect response

            ## Control themes

            - declares a content handling policy
- limits framing and embedding
- sets an intentional cache policy

            Each rule requires explicit offline evidence. A rule definition adds report context and does not initiate a scan or execute supplied reproduction text.
